# malli — Haute Gastronomy & Five Blooming Rooms

> **"A Floral Journey of Flavours · Five Private Dining Rooms"**

An extraordinary, Michelin-caliber restaurant website designed for **malli**, celebrating Indian culinary heritage reimagined in a contemporary luxury setting.

🌐 **Live Experience**: [https://avaneeshmogilicherla-dotcom.github.io/malli/](https://avaneeshmogilicherla-dotcom.github.io/malli/)

---

## 🌸 Creative Direction & Design Highlights

### 1. 3D Continuous Rotating Emblem
* Continuous 360° 3D spinning logo stage designed to match team lead direction, reading **malli** on both front and back faces without mirrored text distortion.
* Responsive depth perspective and subtle interactive mouse-tilt parallax.

### 2. The Five Blooming Private Dining Rooms (Video Showcase)
Step inside five distinct immersive rooms, arranged chronologically matching the architectural walkthrough:
1. **01. Jasmine** — *The Room of Fragrance*: Begins with the grand gold entrance and shimmering logo reveal, leading into serenity and pure ivory lattice aesthetics.
2. **02. Dahlia** — *The Room of Passion*: Bold crimson tones, dramatic lighting, and charcoal tandoor craftsmanship.
3. **03. Tulip** — *The Room of Elegance*: Modern geometry, luminous ambient lighting, and delicate pastry artistry.
4. **04. Magnolia** — *The Room of Serenity*: Soft blush accents and tranquil coastal flavours.
5. **05. Gardenia** — *The Room of Mystique*: Dark velvet luxury and deep nocturnal sensory pairings.

* **Embedded Cinematic Video Tours**: Each room slide renders its own HD video walkthrough with custom audio mute/unmute toggles.

### 3. Continuous Infinite Marquee
* Gracefully slow, dual-group CSS transform animation moving infinitely without jumps, gaps, or clipping.
* Soft gradient edge dissolve masks.

### 4. Haute Gastronomy Menu (USD $)
* Curated luxury dining menu across **Starters**, **Mains**, **Desserts**, and **Drinks** with realistic fine-dining pricing in US Dollars ($).

### 5. Private Dining & Table Reservations
* Tailored reservation request form with instant room selection, guest counts, and special requests.

## 🚀 How to Run & Preview Locally

The site is completely self-contained with all images, stylesheets, and scripts saved locally in `assets/`.

### Option A: Open Directly
Double-click `index.html` to open it directly in Chrome, Edge, Safari, or Firefox.

### Option B: Local Web Server
```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve
```
Then visit `http://localhost:8080`.
